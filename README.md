# Flowko Rezervacije

Online booking for salons and small businesses.

Customers book an appointment online. The business sees every booking on one
calendar, together with its workers, their working hours and its services.
Flowko Rezervacije is a hosted service, run by Flowko for its clients in
Slovenia.

- User documentation (in Slovenian): [docs.flowko.si](https://docs.flowko.si)
